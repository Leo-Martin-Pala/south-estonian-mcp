# Võro: Noun Morphology and Cases

## Number
- **Nominative Singular:** Unmarked stem or lexical `-q` (`mõts`, `kastõq`).
- **Nominative Plural:** Marked with glottal stop **`-q`** (practical `'`), NEVER Standard Estonian `-d`:
  - `mõts` -> `mõtsaq` ("forests"), `talo` -> `taloq` ("farms"), `inämb` / `suur` -> `suurõq` ("big ones"), `lats` -> `latsõq` ("children").
  - (Watch out: `-d` in Võro nouns is normally singular partitive on vowel/monosyllabic stems, e.g., `tuud`, `muud`, `hääd`, `tüüd`, `tiid`, `viid`, NOT plural nominative!)

## Core Case System (Contrasted with Standard Estonian)
| Case | Võro Ending(s) | Võro Example | Estonian Contrast (Leakage!) |
| --- | --- | --- | --- |
| Nominative pl | `-q` | `puuq`, `mõtsaq` | *puud*, *metsad* |
| Genitive sg | vowel stem / grade change | `mõtsa`, `keele`, `tüü` | *metsa*, *keele*, *töö* |
| Partitive sg | `-d`, `-t`, `-Ø`, vowel | `tuud`, `hääd`, `kiilt`, `mõtsa` | *seda*, *head*, *keelt* |
| Partitive pl | vowel plural (`-i`/`-o`/`-e`/`-u`), `-sit`, `-it`, `-idsi` | `mõtso`, `kiili`, `inemisi` | Avoid Estonian `-sid` |
| Illative (into) | short geminate/stem, `-he`, `-de`, `-te` | `mõtsa`, `tarrõ`, `liina`, `kerkohe` | Avoid Estonian `-sse` / `-desse` / `-tesse` |
| Inessive (in) | `-n` (core Võro), `-h` / `-hn` (eastern/Seto-border) | `mõtsan`, `koton`, `liinan` (`mõtsah`) | Est. `-s` (`metsas`) |
| Elative (out of) | `-st` | `mõtsast`, `kotost` | Overlaps with Est. `-st` |
| Allative (onto) | `-lõ`, `-le` | `maale`, `talolõ`, `muialõ` | Est. `-le` (back harmony -> `-lõ`) |
| Adessive (on/at) | `-l` | `maal`, `talol` | Overlaps with Est. `-l` |
| Ablative (off) | `-lt` | `maalt`, `talolt` | Overlaps with Est. `-lt` |
| Translative (into state) | **`-s`** | `suurõs`, `karakõrraldajas`, `hääs` | Avoid Estonian `-ks` |
| Terminative | `-ni`, `-niq` | `kotsilõni`, `hummoguni` | Overlaps with Est. `-ni` |
| Essive | Rare in `-na`; prefer `-s` / `-st` or postpositions | `nuurõn` / `latsõst pääst` | Avoid productive Estonian `-na` |
| Abessive (without) | **`-lda(q)`**, **`-ldä(q)`** | `rahuldaq`, `tiidmäldä` | Est. `-ta` (`rahata`) |
| Comitative (with) | **`-ga(q)`** | `latśiga`, `sõbragaq` | Est. `-ga` (no vowel harmony) |

## Demonstratives & Pronouns
- `tää` / `timä` ("he/she"), `naaq` / `näq` ("they"); demonstrative `seo` / `sjoo` ("this"), `tuu` ("that"), pl `naaq`, `nooq` (gen `nõidõ`, part `noid`).
- Possessive/reflexive `uma` ("own", never Estonian *oma* in core Võro standard prose).
