# Võro: Distinctive Vocabulary and False Friends

## High-Frequency Distinctive Lexicon (Võro vs Standard Estonian)
| Võro Word | Meaning (ET / EN) | Estonian Trap / False Friend Note |
| --- | --- | --- |
| `om` / `ommaq` | *on* / is, are | Do not turn into Estonian `on` |
| `lätt` | *läheb* / goes | 3sg of `minemä` (Estonian *läks* lookalike vs `läts`) |
| `tiiq` / `tetäq` / `tege` | *tee* / *teha* / *teeb* | 2sg imp / inf / 3sg pres |
| `täämbä` | *täna* / today | Not Estonian *tõmba* |
| `põrõhõlla` / `noq` | *praegu* / now | Prefer over Estonian `nüüd` |
| `väega` (`väegaq`) | *väga* / very | Preserve back-vowel diphthong `äe` |
| `pallo` | *palju* / much, many | Avoid Estonian `palju` |
| `kõgõ` | *kõige*, *alati*, or *väga* | Context disambiguates "always / very / most" |
| `ull` | *rumal, loll* / foolish | Can also mean *hull*; check context |
| `puulpäiv` | *laupäev* / Saturday | Literally "half-day" |
| `põimukuu` | *august* / August | Traditional month name ("harvest month") |
| `susi` (gen. `soe`) | *hunt* / wolf | **`soe`** is genitive of *susi* ("wolf's"), NOT Estonian *soe* ("warm", Võro `lämmi`)! |
| `kuulma` | *kuulma* / hear (or also sense/smell contexts) | Check surrounding arguments |
| `piní` / `pini` | *koer* / dog | Standard South Estonian word for dog |
| `tsiga` (gen. `tsia`) | *siga* / pig | Word-initial palatal affricate `ts` |
| `lats` (pl `latsõq`) | *laps* / child | `-ts` corresponds to Est. `-ps` |
| `ütś` / `üts`, `katś` / `kats` | *üks*, *kaks* / one, two | Assibilated `*kt -> tt -> ts` / `*ks -> ts` |
| `kõnõlõma` | *rääkima, kõnelema* / speak | 3sg `kõnõlõs` |
| `kaema` | *vaatama* / look | Distinct from *nägema* |
| `man` / `mano(q)` / `mant` | *juures* / *juurde* / *juurest* | Core spatial postpositions |
| `suurõq inemiseq` | *täiskasvanud* / adults | Idiomatic compound phrase |
| `midägi` | *midagi* / something | Keeps front-vowel harmony `ä` |
| `miä` / `mis` | *mis* / what | Both occur; check clause |

## Orthographic False-Friend Reminders
- `-s` on finite verbs (`eläs`, `kirotas`, `mõtlõs`) is usually **present 3sg**, not past.
- Final `-q` on `mõtsaq` ("forests") vs `võtaq` ("take!") vs `tetäq` ("to do") vs `olõq` (connegative stem) has four distinct syntactic functions determined by clause role.
- When uncertain about lexical items or inflections, query `lookup_word`, `analyze_word`, `lookup_words`, and `find_cognates` before coining calques.
