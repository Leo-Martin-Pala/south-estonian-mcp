# Tartu: Noun Morphology and Cases

## Number & Stem Alternation
- **Nominative Plural:** Traditionally endingless (`kõtu olliva tühä` "the stomachs were empty" in *murdekorpus_tartu*) or matching South Estonian vowel-stem plurals (`nuu` = "need", `naa` = "nemad"); avoid importing Standard Estonian `-d` where genuine dialect uses endingless plural.
- **Partitive Singular / Plural:** Vowel/stem partitives (`üte`, `süvvä`, `suvve`) and plural `-it`/`-id`/`-sit` / vowel plurals rather than Estonian `-sid`.

## Core Case Endings
| Case | Tartu Ending(s) | Corpus Example & Contrast |
| --- | --- | --- |
| **Inessive (in)** | **`-n`** | `lehmäkarjan` ("in the cattle herd"), `tsiakarjan`, `kodon` |
| **Illative (into)** | Short stem / geminate, **`-de`**, or `-he` | `kiirdu`, `kodu`, `tarrõ` — avoid Estonian `-sse` / `-desse` / `-tesse` |
| Elative (out of) | `-st` | `kotust` ("from home / place") |
| Allative / Adessive / Ablative | `-le` / `-lõ`, `-l`, `-lt` | `näile` ("to them"), `karjal` |
| **Translative** | **`-st`**, **`-ss`**, or **`-s`** | Contrast Estonian `-ks` |
| Comitative / Abessive | `-ga`, `-lda` / `-ldä` / `-lda` | Shared South Estonian suffixes without `q` |
