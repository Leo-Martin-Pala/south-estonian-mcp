# Mulgi: Verb Conjugation and Negation

## Key Verbal Distinctions (Do Not Over-Apply Võro or Estonian Rules!)
1. **3sg Present (`-b` / `-p` or endingless):**
   - Unlike Võro/Seto, **Mulgi legitimately uses `-p` or `-b` in 3sg present** (`annap`/`annab`, `tulep`/`tuleb`, `teep`/`teeb`), OR endingless/stem forms; **`-s` 3sg present is NOT universal across Mulgi** (do not apply the Võro `-s` present rule indiscriminately to Mulgi verbs!).
   - **`om`** covers 3sg and 3pl ("is / are"), e.g. `"juhi om käinu"`, `"Obese om eesti tõugu"`.
   - **1sg present** can be endingless (`ma tule`, `mia ole`).
2. **3pl Present:** **`-ve` / `-va` / `-vä`** (`tegeve`, `tuleva`, `eläve`), NOT Standard Estonian `-vad`.
3. **The *ma*-Infinitive (`-me` / `-mä` / `-ma`) — Crucial Disambiguation Rule:**
   - **Karksi** uses **`-me`** (`tegema` -> `tegeme`), while **Tarvastu** uses `-ma`/`-mä` on two-syllable verbs and `-me` on longer stems!
   - **Syntactic warning:** After verbs governing infinitives (*nakkama*, *saama*, *tahtma*, etc.), parallel `-me` forms are **infinitives**, NOT 1st-person plural present! Always resolve syntactically, not by `-me` spelling alone!
4. **Supine Inessive & Abessive (`-men`/`-man` and `-te`/`-de`):**
   - `"saaman"` ("getting / in the act of getting"), `"tegemän"` / `"tegemen"`.
   - **`-te` / `-de` express absence (abessive)**, including verbal abessive forms — always preserve the absence meaning rather than turning it into a positive infinitive!
5. **Active Past Participle (`-nu` / `-nü` / `-n` / `-nd`) & Passive (`-t` / `-d` / `-tu` / `-tü`):**
   - `"om käinu"` ("has gone / been"), `"oln"`, `"tennü"`, `"pandu"` — NEVER Estonian `-nud` / `-tud` / `-dud`.
6. **Impersonal & Conditional:**
   - Impersonal present: **`-tas` / `-täs` / `-tes` / `-das`** (`süvväs` "is eaten", `pandas` "is put") — never Estonian `-takse/-dakse`.
   - Conditional: **`-ss` / `-ssi` / `-se`** (`oless` "would be", note surface overlap with translative `-ss`!).
7. **Past Negation (`es`):**
   - **`es` + verb** marks past negation (`es tii`, `es ole`, `es näe`), NOT Estonian `ei + -nud`. Reject `pole`/`polnud`.
