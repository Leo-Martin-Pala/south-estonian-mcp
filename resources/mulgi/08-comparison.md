# Mulgi Adjective Comparison & Declension

## Degrees of Comparison

- **Comparative (keskvõrre):** formed with `-mb` or `-mp` (e.g. `suuremb` 'bigger', `kergemb` 'lighter', `nooremp` 'younger', `valgemp` 'whiter', `paremb` 'better', `uvvemb` 'newer'). In stem-final / non-initial syllable gradation, `-p` alternates with `-b-` in the genitive (e.g. `kaugep` : gen. `kaugebe` : part. `kaugepet`).
- **Superlative (ülivõrre):** formed analytically with `kige` + comparative:
  - `kige paremb` ('best')
  - `kige uvvemb` ('newest')
  - `kige rohkemb` ('most')

## Adjective Declension (`kõllane` 'yellow', `toores` 'raw')

| Case | Endings (Sg / Pl) | Sg (`kõllane`, `toores`) | Pl (`kõllatse`, `tuure`) |
|---|---|---|---|
| **Nominative** | Ø / `-de`, `-se` (Krk) | `kõllane`, `toores` | `kõllatse`, `tuure` |
| **Genitive** | Ø / `-de`, `-te` | `kõllatse`, `tuure` | `kõllaste`, `tooreste` |
| **Partitive** | Ø, `-da`, `-dä`, `-d`, `-t` / `-id`, `-it`, `-sit` | `kõllast`, `toorest` | `kõllatsit`, `tuurit` |
| **Illative** | `-s(s)`, `-se`, `-de`, `-te`, Ø | `kõllatsese`, `tuurese` | `kõllatsise`, `toorestese` |
| **Inessive** | `-n` | `kõllatsen`, `tuuren` | `kõllatsin`, `tooresten` (`tuurin`) |
| **Elative** | `-st` | `kõllatsest`, `tuurest` | `kõllatsist`, `tuurist` |
| **Allative** | `-l(e)` | `kõllatsel(e)`, `tuurel(e)` | `kõllatsil(e)`, `tuuril(e)` |
| **Adessive** | `-l` | `kõllatsel`, `tuurel` | `kõllatsil`, `tuuril` |
| **Ablative** | `-lt` / `-ld` | `kõllatselt/d`, `tuurelt/d` | `kõllatsilt/d`, `tuurilt/d` |
| **Translative** | `-s(s)` | `kõllatses`, `tuures` | `kõllatsis`, `toorestes` |
| **Terminative** | `-ni` | `kõllatsini`, `tuureni` | `kõllasteni`, `tooresteni` |
| **Essive** | `-n` | `kõllatsen`, `tuuren` | `kõllatsin`, `tooresten` |
| **Abessive** | `-te`, `-de` | `kõllatsede`, `tuurede` | `kõllatsidete`, `toorestede` |
| **Comitative** | `-ge` | `kõllatsege`, `tuurege` | `kõllatsid(e)ge`, `toorestege` |
