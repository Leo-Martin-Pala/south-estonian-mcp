# Mulgi Inflection Tables

## Noun Case Paradigm (14 Cases)

Model nouns: `kuul` ('school', with vowel lowering `uu` → `oo` in weak grade) and `poiss` ('boy').
Note: Mulgi nominative plural is **endingless** (no `-d`, no `-q`), e.g. `kooli`, `poisi`, `muna`, `latse`, `päevä`.

| Case | Endings (Sg / Pl) | Singular | Plural |
|---|---|---|---|
| **Nominative (Nimetav)** | Ø / Ø (gen. stem) | `kuul`, `poiss` | `kooli`, `poisi` |
| **Genitive (Omastav)** | Ø / `-de`, `-te`, `-e` | `kooli`, `poisi` | `kuule`, `poiste` |
| **Partitive (Osastav)** | Ø, `-da`, `-dä`, `-d`, `-t` / `-id`, `-it`, `-sit`, `-si`, `-e`, `-i`, `-u`/`-ü` | `kuuli`, `poissi` | `kuule`, `poisse` |
| **Illative (Sisseütlev)** | `h` + stem V, `-s(s)`, `-se`, `-de`, `-te`, Ø | `kuuli`, `poisiss`, `pähä` | `kuules`, `poistess` |
| **Inessive (Seesütlev)** | `-n` | `koolin`, `poisin` | `kuulen`, `poisten` |
| **Elative (Seestütlev)** | `-st` | `koolist`, `poisist` | `kuulest`, `poistest` |
| **Allative (Alaleütlev)** | `-l(e)` | `koolil(e)`, `poisil(e)` | `kuulel(e)`, `poistel(e)` |
| **Adessive (Alalütlev)** | `-l` | `koolil`, `poisil` | `kuulel`, `poistel` |
| **Ablative (Alaltütlev)** | `-lt` / `-ld` | `koolilt/d`, `poisilt` | `kuulelt`, `poistelt` |
| **Translative (Saav)** | `-s(s)` | `koolis`, `poisis` | `kuules`, `poistes` |
| **Terminative (Rajav)** | `-ni` | `koolini`, `poisini` | `kuuleni`, `poisteni` |
| **Essive (Olev)** | `-n` | `koolin`, `poisin` | `kuulen`, `poisten` |
| **Abessive (Ilmaütlev)** | `-te`, `-de` | `koolite`, `poisite` | `kuulede`, `poistete` |
| **Comitative (Kaasaütlev)** | `-ge` | `koolige`, `poisige` | `kuulege`, `poistege` |

### Postpositions Preferred Over Case Endings

Mulgi idiomatically prefers postpositions (with genitive) over bare local/abessive/comitative case suffixes:
- **Illative:** `sissi` (`püügle sissi`, `puie sissi`)
- **Inessive:** `sihen` (`mõtsa sihen`, `koti sihen`)
- **Elative:** `siist` (`kere siist`, `lavva siist`)
- **Allative / Adessive / Ablative:** `pääle`, `pääl`, `päält`/`pääld` (`lavva pääle`, `Mustla pääl`, `turu pääld`)
- **Proximity:** `manu`, `man`, `mant`; `kõrva`, `kõrvan`, `kõrvast`; `ala`, `all`, `alt`; `ette`, `ihen`, `iist`; `taga`, `taga`, `tagast`; `viirde`, `veeren`, `veerest`
- **Abessive:** `ilma` + abessive (`ilma latsete`, `ilma naisete`)
- **Comitative:** `üten` + comitative (`üten vellege`, `miuge üten`)

## Key Verbal Morphology Features

- **1sg present & past:** endingless (`ma tule` / `tulli`, `ütle` / `ütli`, `kõnni` / `kõndsi`, `ole` / `olli`).
- **3sg present:** `-p` (`tulep`, `ehitep`, `läep`) or endingless in vowel/assimilated stems.
- **3pl present:** `-ve` (`lendäve`, `tuleve`, `kõneleve`); **3pl past:** `-sive` / `-ve` (`kiiksive`, `ollive`).
- **Conditional:** `-ss` (corresponding to North Estonian `-ks`, e.g. `mia tahass`, `lääss`).
- **Past negation:** preposed particle `es` (`es ole`, `es taha`, `es mõista`, `es lää`).
- **Present negation:** `ei` (`ei ole`, `ei taha`, `ei putu`).
- **`ma`-infinitive (`-me` / `-mä` / `-ma`):**
  - **Karksi:** always `-me` (`andme`, `kandme`, `juume`, `süüme`, `laulme`, `tuume`, `viime`, `löüdme`, `kütme`, `kurtme`; 3-syllable `lubame`, `vedäme`, `kirjuteme`, `nägeme`, `lugeme`, `mineme`, `magame`, `jahtume`, `õpme`).
  - **Tarvastu:** disyllabic verbs take `-ma` / `-mä` (`andma`, `süümä`, `löüdmä`, `kütmä`, `õpma`), while trisyllabic and longer verbs take `-me` (`lubame`, `vedäme`, `kirjuteme`, `nägeme`, `mineme`).

## Phonological Alternations Affecting Inflection

- **No word-initial `h-`:** `ammas` ('tooth'), `unt` ('wolf'), `iir` ('mouse'), `obene` ('horse'), `aige` ('sick'); word-internal `-h-` is preserved (`pähä`, `mahan`, `tühü`, `tühün`, `ehen`).
- **Mid-vowel raising / lowering in long stems:** `kuul` : `kooli` : `.kuuli`, `süük` : `söögi`, `puut` : `poodi`, `piit` : `peedi`, `kiil` : `keele`, `suul` : `soola`.
- **Diphthong `u`/`ü` → `vv` in weak grade:** `laud` : `lavva`, `põud` : `põvva`, `raud` : `ravva`, `aud` : `avva`, `lõug` : `lõvva`, `kuus` : `kuvve`, `kuub` : `kuvve`, `müvvä`, `tuvva`.
- **Non-initial `a`/`ä` → `e`:** from the 3rd syllable onward (and from the 2nd syllable in Karksi): `armasteme`, `tunnisteme`, `kirjuteme`.
- **No non-initial `o`:** raised to `u` (`autu`, `setu`, `Võru`).
- **Word-initial consonant cluster simplification:** `repp` ('stairs'), `leit` ('dress'), `riit` ('chalk'), `limp` ('dumpling').
