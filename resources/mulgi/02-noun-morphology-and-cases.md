# Mulgi: Noun Morphology and Cases

## Number
- **Nominative Plural:** Can **lack an overt `-d` or `-q` ending**, ending in a stem vowel instead:
  - `latse` ("children"), `muna` ("eggs"), `sia` ("pigs"), `juhi` ("leaders"), `obese` ("horses").
  - **Rule:** *"juhi om käinu õpetust saaman"* / *"Obese om eesti tõugu"* -> `juhi` and `obese` are **plural** nominatives matching plural/unmarked `om` — always resolve number from agreement and context!

## Core Case System (Contrasted with Estonian & Võro)
| Case | Mulgi Ending(s) | Mulgi Notes / Examples | Contrast |
| --- | --- | --- | --- |
| Nominative pl | `-Ø` (stem vowel) | `latse`, `muna`, `sia`, `juhi`, `obese` | Est. `-d`; Võro `-q` |
| Genitive / Partitive sg | Stem alternation | `kiil / keele / kiilt`, `kuul / kooli / kuuli`, `puut / poodi / puuti` | Grade/vowel raising in nom sg |
| Partitive pl | Vowel plural (`-e`, `-i`, `-u`), `-id`, `-sit` | `latsi`, `munu` | Avoid Est. `-sid` |
| Illative (into) | Short geminate/vowel or `-de`/`-te` | `tuppa` / `tupa`, `linna`, `metsä`, `kätte` | Avoid Est. `-sse` / `-desse` / `-tesse` |
| **Inessive (in)** | **`-n`** | `Talnan` ("Tallinnas"), `kodon`, `mõtsan` | Same `-n` as core Võro; Est. `-s` |
| Elative / Allative / Adessive / Ablative | `-st` / `-le` / `-l` / `-lt` | `meile`, `Mulgimaal` | Compare Võro back `-lõ` |
| **Translative** | **`-ss`** (or `-s`) | Distinct from conditional `-ss` by syntax | Avoid Estonian `-ks` |
| **Abessive (without)** | **`-te` / `-de`** (plus `-te/-de` on verbs!) | Expresses absence; do not turn into infinitive! | Est. `-ta`, Võro `-lda` |
| **Comitative (with)** | **`-ge`** (also `-ga`) | Characteristic western South Estonian **`-ge`** | Est./Võro `-ga` |

## Spatial Postpositions & Quantifiers
- Distinct spatial series: `man` (at/by) / `manu` (to) / `mant` (from); `pääl` (on) / `pääle` (onto) / `päält` (off).
