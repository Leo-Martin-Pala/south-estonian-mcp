# Mulgi: Distinctive Vocabulary and False Friends

## Critical Mulgi Lookalikes & Idioms (From Corpus Audit & Dialect Profiles)
| Mulgi Expression | Standard Estonian / English Meaning | Critical Trap / Rule |
| --- | --- | --- |
| `sii` | *see* / this, it | Looks like Estonian; in Mulgi `sii = see` (`Sii olli meile armas kotus.`) |
| `nii` | *need* / these, those | NOT Estonian adverb *nii* ("so") by default — **`nii = need`** ("these")! Check plural agreement! |
| `mes` | *mis* / what | `"Mes sii om, mes Talnan süvväs..."` |
| `mia` / `ma`; `sia` / `sa` | *mina* / *sina* | Western South Estonian pronouns |
| `mehele minema` | *abielluma* (woman marrying) | Idiomatic! Never translate literally as "going to the men / plural males"! |
| `kotus` | *koht* / place | `"armas kotus"` |
| `obese` (`obu`) | *hobused* / horses | Missing initial `h` + vowel plural `-e` = "horses" |
| `latse` / `sia` / `muna` | *lapsed* / *sead* / *munad* | Endingless nominative plurals! |
| `äste` | *hästi* / well | Initial `h`-drop |
| `pallu` / `väige` | *palju* / *väga* | Compare Võro `pallo` / `väega` |
| `nüid` | *nüüd* / now | Palatal diphthongization |
| `üits` / `kaits` | *üks* / *kaks* | Shared western/Tartu epenthesis |
| `kodo` / `kodon` | *kodu* / *kodus* | `-n` inessive |
| `süvvä` / `lüvvä` / `süvväs` | *süüa* / *lüüa* / *süüakse* | Consonant glide `vv` |
| `sõss` | *siis* / then | Or `sis` |
| `Talnan` | *Tallinnas* | Syncopated `-n` inessive (`uitsainus_mulgimaa`) |

## Cross-Dialect Guardrails
- Do NOT "correct" Mulgi `-b/-p`, `-ge` comitative, `-me` infinitives, or `h`-less words (`obese`, `ain`, `äste`) to Võro (`-q`, `-gaq`, `-man`) or Standard Estonian (`-vad`, `-nud`, `-sse`, `hobused`).
- Always verify lexical senses in `eki_mulgi_dictionary` / `smugri4_mulgi_dictionary` via `lookup_words(..., lang="mulgi")`.
